# SigCom LINCS

## Overview

SigCom LINCS is a search engine for over 1.5 million gene expression signatures generated from the Library of Integrated Network-Based Cellular Signatures (LINCS), Gene Expression Omnibus (GEO), and Genotype-Tissue Expression (GTEx) projects.

The platform enables rapid similarity search between user-provided gene signatures and publicly available perturbation signatures to identify drugs, genes, pathways, diseases, and perturbations that either mimic or reverse a biological state.

SigCom LINCS also provides searchable metadata for datasets, signatures, genes, perturbagens, cell lines, and experimental conditions.

## When to Use This Skill

- identifying drugs or perturbations that mimic or reverse a gene expression signature
- searching LINCS, GEO, and GTEx gene expression signatures
- searching signatures by gene, drug, disease, tissue, cell line, or perturbation
- retrieving and analyzing signature and dataset metadata
- discovering CRISPR, overexpression, shRNA, siRNA, and compound perturbation signatures


## Core Capabilities 

**Metadata Search:** search datasets, signatures, genes, perturbagens, diseases, cell lines, tissues, and experimental metadata.
- Example queries:
  - "find signatures involving dexamethasone"
  - "find CRISPR knockout signatures"

**Signature Similarity Search:** identify signatures that mimic or reverse an input gene signature using fast enrichment analysis across millions of signatures.
- Example queries:
  - "find drugs that reverse my disease signature"
  - "which perturbations mimic this signature?"

**Metadata Analytics:** Count datasets, enumerate metadata values, inspect searchable fields, and summarize collections.
- Example queries:
  - Count endpoint: "how many datasets use L1000?"
  - Value Count endpoint: "what cell lines are most common for this perturbation?"
  - Key Count endpoint: "what metadata fields can I query?"

## API Documentation

Metadata URL: https://maayanlab.cloud/sigcom-lincs/metadata-api
- Mostly for:
  - fast full-text search
  - data aggregates query
  - and is structured using LoopBack 4 queries

Data URL: https://maayanlab.cloud/sigcom-lincs/data-api
- Mostly for:
  - enrichment analysis against LINCS signatures

### Metadata Uses

**1. Full-text metadata search**

Search for datasets, signatures, or genes.

Available mappings:
- DSGCs: resources
- Datasets: libraries
- Signatures: signatures
- Genes: entities

**Example code** for finding datasets (libraries) containing word "proteomics":

```python
import requests
import json

API_URL = "https://maayanlab.cloud/sigcom-lincs/metadata-api/libraries/find"

payload = {
    "filter": {
        "where": {
            "meta": {
                "fullTextSearch": "proteomics"
            }
        },
        "limit": 2
    }
}

res = requests.post(API_URL, json=payload)
results = res.json()

print(json.dumps(results, indent=2))
```

**2. Filtering by metadata fields**

SigCom LINCS stores its metadata as semi-structured JSON serialized entries, allowing results filtering via metadata fields.

**Example code** on finding signatures perturbed with CRISPR Knockdown:

```python
import requests
import json

API_URL = "https://maayanlab.cloud/sigcom-lincs/metadata-api/signatures/find"

payload = {
    "filter": {
        "where": {
            "meta.pert_type":  "CRISPR Knockdown"
        },
        "limit": 2
    }
}

res = requests.post(API_URL, json=payload)
results = res.json()

print(json.dumps(results, indent=2))
```

```python
import requests
```

**4. Counting the results**

Count endpoint ``https://maayanlab.cloud/sigcom-lincs/metadata-api/<model>/count`` counts number of entries in a model. Users can also pass a ``where`` filter to get filtered count.

**Example code** on retrieving number of datasets (libraries) that use L1000 mRNA profiling assay:

```pythonn

import json

API_URL = "https://maayanlab.cloud/sigcom-lincs/metadata-api/libraries/count"

    "meta.assay": "L1000 mRNA profiling assay"
}

res = requests.get(API_URL, params={"where": json.dumps(payload)})

print(json.dumps(results, indent=2))
```

**5. Fetching the value counts**

Value count endpoint ``https://maayanlab.cloud/sigcom-lincs/metadata-api/<model>/value_count`` returns the count of values of a specific field. Useful for obtaining top assays, cell line, perturbations of a model.

**Example code** on retrieving top 25 cell lines of signatures perturbed with dexamethasone:


### Performing Signature Search

Signature search is a multi-step process using both metadata and data APIs.

**1. Convert gene names to UUIDs using the metadata API**

```python
import requests
import json

METADATA_API = "https://maayanlab.cloud/sigcom-lincs/metadata-api/"
DATA_API = "https://maayanlab.cloud/sigcom-lincs/data-api/api/v1/"

input_gene_set = {
    "up_genes": ["TARBP1", "APP", "RAP1GAP", "UFM1", "DNAJA3", "PCBD1", "CSRP1"],
    "down_genes": ["CEBPA", "STAT5B", "DSE", "EIF4EBP1", "CARD8", "HLA-DMA", "SERPINE1"]
}

all_genes = input_gene_set["up_genes"] + input_gene_set["down_genes"]

payload = {
    "filter": {
        "where": {
            "meta.symbol": {
                "inq": all_genes
            }
        },
        "fields": ["id", "meta.symbol"]
    }
}
res = requests.post(METADATA_API + "entities/find", json=payload)
entities = res.json()

for_enrichment = {
    "up_entities": [],
    "down_entities": []
}

for e in entities:
    symbol = e["meta"]["symbol"]
    if symbol in input_gene_set["up_genes"]:
        for_enrichment["up_entities"].append(e["id"])
    elif symbol in input_gene_set["down_genes"]:
        for_enrichment["down_entities"].append(e["id"])

print(json.dumps(for_enrichment, indent=2))
```

**3. Perform signature search using the ranktwosided endpoint of the data API**

Generally, ranktwosided endpoint takes inputs: up and down gene sets, a limit, and database used for enrichment. Data API returns top matching signatures along with enrichment scores, ranked by sum of z-up and z-down scores (z-sum). Positive z-sum indicates that the signature is a mimicker while negative z-sum means it is a reverser.

```python
query = {
    **for_enrichment,
    "limit": 2,
    "database": "l1000_xpr"
}

res = requests.post(DATA_API + "enrich/ranktwosided", json=query)
results = res.json()

# Optional, multiply z-down and direction-down with -1
for i in results["results"]:
    i["z-down"] = -i["z-down"]
    i["direction-down"] = -i["direction-down"]
print(json.dumps(results, indent=2))
```

**4. Resolve signature UUIDs using the metadata API**

```python
sigids = {i["uuid"]: i for i in results["results"]}

payload = {
    "filter": {
        "where": {
            "id": {
                "inq": list(sigids.keys())
            }
        }
    }
}

res = requests.post(METADATA_API + "signatures/find", json=payload)
signatures = res.json()

## Merge the scores and the metadata
for sig in signatures:
    uid = sig["id"]
    scores = sigids[uid]
    scores.pop("uuid")
    sig["scores"] = scores

print(json.dumps(signatures[0:2], indent=2))
```
